## 3. 方向、14:30 分界与指标口径

当前默认的方向关系如下：

| 对象 | 做空 | 做多 |
|---|---|---|
| 原始 score 与指定阈值比较 | `score < threshold` | `score >= threshold` |
| 最终零中心 pred | `pred < 0` | `pred >= 0` |
| 策略收益 | `-Tag` | `Tag` |
| 赚钱条件 | `Tag < 0` | `Tag > 0` |

统一表达式为 `strategy_return = direction * Tag`，其中空头方向为 -1，多头方向为 +1。空头区间的平均策略收益是 `-mean(Tag)`；不能直接把负 Tag 当成策略亏损。

当前没有不交易区间，恰好等于阈值时归为做多。早期讨论和部分旧表曾把中心点单列、不交易，或使用左闭右开/左开右闭分箱。复盘历史报告时必须按该报告的源码处理端点，不把早期规则套用到当前最终 Parquet。

14:30 的规则是：`Datetime < 14:30` 为前段，`Datetime >= 14:30` 为后段；14:30 整点属于后段。这是基于已观察到的分布与预测表现差异选择的研究切点，不是已被证明有因果作用的市场规律。当前批量漂移按前后两个时段分别计算，每个时段汇总全部合约；Web 实验页还允许选择合约分组、不同切点、只保留其中一段等，因此不同流水线不是同一个实验。

三个容易混淆的比例：

- 做空占比：预测为空的样本数 / 全部样本数，反映方向分配。
- 真实负类占比：`Tag < 0` 的样本数 / 全部样本数，反映实际负收益样本比例；不是历史真实执行过的空单占比。
- 做空 Precision：预测为空且 `Tag < 0` 的样本数 / 预测为空的样本数，反映空头预测质量。

当前收益图的胜率为正策略收益样本数 / 非零策略收益样本数，排除 `Tag = 0`。`utils/metrics.py` 的通用 `directional_metrics()` 及部分历史报告的 Precision、总体准确率仍使用包含零收益样本的分母。`utils/segmented_drift.py` 的 `directional_hit_rate()` 排除零 Tag。引用指标时应同时说明函数或分母，不能把这几种数字直接当作同口径。

平均盈亏比是 `平均盈利 / abs(平均亏损)`，不是赚钱单数 / 亏钱单数。历史需求曾从盈亏单数比改成胜率，因此旧表中的相似列名要结合 README 理解。Tag 图使用 bp 时，`1 bp = 0.0001 = 0.01%`，图上 100 bp 对应原始收益率 0.01，而不是 100%。

## 4. 当前漂移修正及参数来源

当前批量流程的唯一参数结果文件是：

```text
result/parameters/segmented_score_drift_selected_parameters.json
```

对每个时段，每日先计算 score 中位数。当天慢速基准 B 是此前全部日中位数的中位数；当天近期中心 R 是只使用此前日中位数更新的 EWMA。半衰期 H 换算为 `alpha = 1 - 2**(-1/H)`，首个有效日以当时的慢速基准初始化近期中心。

开发段估计固定平衡偏移 `b = median(score - R)`，最终使用：

```text
effective_center = R + b
offset = effective_center - B
adjusted_score = score - offset
pred_final = adjusted_score - B = score - (R + b)
```

所以“修正后的 score 与 B 比较”和“原始 score 与 R+b 比较”完全等价；导出为 `pred_final` 后直接与 0 比较。

同一天、同一处理分组内的分数都减去相同偏移，因此该分组内部排序保持不变。但不同日期或分组的偏移不同，混合全部日期后计算的排序和 AUC 可能改变。此方法校正的是分布位置，不能保证保存原始概率校准，也不能保证提高胜率或收益。

当前固定数据上的时间切分：

- 冷启动最少 20 个交易日，同时覆盖首个完整自然月，实际为 2024 年 1 月的 21 个交易日。
- 冷启动样本不进入最终 Parquet；剩余 579 个交易日、1,667,520 条样本。
- 开发有效段为 519 个交易日。
- 最后 60 个交易日为测试段，2026-04-01 至 2026-06-30，不参与半衰期及固定 b 的选择。

半衰期通过网格搜索选择，候选为 `1, 2, 5, 10, 20, 40, 60, 90, 120` 个交易日。每个时段独立评估，要求开发段做空占比约 49%～51%，优先最小化月度中心残差的平均绝对值，以相邻月中心残差变化的平方均值作为次级排序。Tag 不参与选择。目标是分布稳定，不是直接优化盈利。

| 时段 | 半衰期 H | alpha | 开发段固定 b |
|---|---:|---:|---:|
| 14:30 前 | 1 | 0.5 | -0.0004985541892309486 |
| 14:30 及以后 | 1 | 0.5 | 0.0013893335192660117 |

“因果”指每天的 B、R 不使用当天及未来日中位数。H 和 b 是利用整个开发段选择的，所以开发段表现仍属于开发期拟合评价，不能称为逐日完全样本外结果。测试段不参与选参，但允许利用已经过去的测试日期数据更新下一天的 B、R，这是在线更新的含义。

## 6. 收益曲线的含义和研究边界

当前单档累计曲线先计算该档每个交易日内样本的等权平均策略收益，再跨交易日做 `cumsum` 单利累计；没有样本的日期补零。对称配对曲线固定低分档做空、高分档做多，分别计算两腿日均收益，再各以 50% 权重合并后单利累计。

六指标图中的“平均每日收益”另有定义：平均每笔策略收益 × 每日开仓次数中位数；统计开仓次数时把范围内无交易日作为 0 次。它是典型频次下的逐笔收益求和指标，不等于累计曲线的日内资金均分收益。

早期固定阈值和10等分累计曲线使用 `cumprod(1 + 日均策略收益) - 1` 复利口径。中文快照 README 中的约 56.06% 等旧结果不能直接与当前单利曲线比较。早期还有按档位固定方向、以总体或分时中位数为阈值的版本；当前零阈值图按每个样本的 pred 符号决定方向，配对图则采用固定多空腿。

等样本分组图主要是事后描述：总体分组后再筛选时间段，与先筛选时间段再独立分组，边界和每档人数会不同。使用全观察期分位数形成的档位不能自动视为事前可部署的阈值。

每个“合约×分钟”样本等权，未完整建模资金占用、重叠持仓、多合约共享资金、杠杆、手续费、滑点、换月和成交约束。因此这些图用于评价信号与收益标签的关系，不能称为已经验证可实现的净值回测。

## 7. Tag 周期及尚未掌握的原始材料

已确认 Tag 的业务含义是收益率。根据历史滞后相关诊断，Tag 可能对应约 30 个交易分钟的未来收益，相邻分钟可能共享大量未来收益区间，尾盘标签还可能跨收盘连接下一交易日。这些都是数据推断，尚未由标签生成源码确认。

在此次已审项目和研究输出目录中，没有找到原始模型训练代码、模型权重、特征工程全链路、原始分钟价格或 Tag 生成源码。因此本交接保存的是“原始 Pred/Tag 结果集及其后处理研究”，不是原模型训练复现包。

收益周期、简单/对数收益或其他变换的精确定义，不能仅凭当前 Parquet 确认。分钟样本高度相关时，172.8 万行不等于172.8 万个独立观察；本项目的描述性比例不能直接替代考虑相关性后的显著性检验。
