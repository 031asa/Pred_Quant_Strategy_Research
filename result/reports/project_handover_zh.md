## 1. 项目目标

研究期货分钟级二分类模型的 Pred 与 Tag 表现。本文档只记录已经明确的数据、逻辑、结果、环境和文件，不包含后续行动计划。

1. 14:30 前后模型分布和预测效果差异明显；
2. 两个时段分别使用什么分类阈值；
3. 不同阈值如何改变多空比例、Precision、Recall和总体准确率；
4. 当前最新计算口径是“基于历史真实负类比例的滚动分位数阈值”。

## 2. 数据与统一定义

- 源数据：`C:\Users\Hello\Downloads\pred_eval.parquet`
- 总样本：1,728,000 行。
- 日期范围：2024-01-03 至 2026-06-30。
- 合约数：12。
- 交易日数：600。
- 有效评估样本：1,670,400 行；最初20个交易日作为滚动预热期，不进入评价。
- `score = pred + 0.5`，并限制在 `[0, 1]`。
- `Tag`的真实业务含义是样本对应的实际收益率，不是原生0/1分类标签。
- `Tag < 0`：实际收益率为负，由此派生为真实负类；做空方向正确。
- `Tag > 0`：实际收益率为正，由此派生为真实正类；做多方向正确。
- `Tag = 0`：收益率为0，既不计为做多正确，也不计为做空正确。
- 14:30前：`Datetime < 14:30`。
- 14:30及以后：`Datetime >= 14:30`，14:30整点属于后一段。
- 当前不设置不交易区间，所有样本必须二分类为做多或做空。

## 3. 当前最新方案：分时滚动分位数阈值

此前关于固定0.5、中位数去偏和Pred统一平移的讨论，均不是当前最终口径。当前方法为：

1. 14:30前后分别计算，不共用阈值；
2. 对每个交易日，只使用同一时段此前20个交易日的数据；
3. 历史真实负类比例：

   `q_short = 历史样本中 Tag<0 的数量 / 历史全部样本数量`

4. 在历史 score 分布上取 `q_short` 分位数：

   `threshold = quantile(historical_score, q_short)`

5. 应用于下一交易日：

   - `score < threshold`：做空；
   - `score >= threshold`：做多。

该方案没有修改原始Pred、没有额外平移、没有不交易区间，也没有使用未来数据。

### 必须记住的方向关系

- 固定阈值0.5时，`score=0.490` 会被判为空单；
- 如果14:30前分位数阈值为0.483，`score=0.490` 会被判为多单；
- 因此把阈值由0.5降至约0.483，是在纠正固定0.5造成的“过度判空”，不是增加空单。
- 如果后续希望增加空单，应提高目标分位数或提高数值阈值。

### 多空方向与收益率计算

阈值左侧和右侧持仓方向相反，因此不能直接用同一个Tag符号计算策略收益：

| 分数位置 | 交易方向 | 策略收益率 | 盈利条件 | 亏损条件 |
|---|---|---|---|---|
| `score >= threshold` | 做多 | `strategy_return = Tag` | `Tag > 0` | `Tag < 0` |
| `score < threshold` | 做空 | `strategy_return = -Tag` | `Tag < 0` | `Tag > 0` |

因此：

- 阈值右侧做多样本的平均策略收益，直接计算 `mean(Tag)`；
- 阈值左侧做空样本的平均策略收益，必须计算 `-mean(Tag)`；
- 全体策略收益可以统一写成：`strategy_return = direction × Tag`，其中做多方向为`+1`、做空方向为`-1`；
- 胜率统一定义为：`strategy_return > 0` 的样本比例。

### 14:30为何是核心分界线

14:30不是任意选择的时间点，而是由实测结果支持的显著分界：

- 固定阈值0.5时，14:30前做多胜率为50.17%；
- 14:30及以后做多胜率为55.70%；
- 尾盘做多胜率比盘中高约5.53个百分点；
- 同一模型在两个时段的score分布和方向质量明显不同，因此阈值和统计必须按14:30前后分别计算。

## 4. 最新实测结果

### 4.1 阈值摘要

14:30前：

- 历史负类占比均值：50.50%。
- 历史负类占比中位数：50.37%。
- 分位数阈值均值：0.484301。
- 分位数阈值中位数：0.483669。
- 阈值范围：0.467876～0.502909。

14:30及以后：

- 历史负类占比均值：46.50%。
- 历史负类占比中位数：46.69%。
- 分位数阈值均值：0.533028。
- 分位数阈值中位数：0.538037。
- 阈值范围：0.483088～0.605154。

### 4.2 固定0.5与分位数阈值对比

14:30前：

| 指标 | 固定0.5 | 滚动分位数阈值 |
|---|---:|---:|
| 实际负类占比 | 50.35% | 50.35% |
| 预测做空占比 | 63.65% | 50.46% |
| 做空胜率/Precision | 51.11% | 51.30% |
| 空头召回率/Recall | 64.61% | 51.41% |
| 做多胜率/Precision | 50.17% | 49.78% |
| 总体方向准确率 | 50.77% | 50.55% |

解释：分位数阈值将盘中预测做空比例校准到实际负类比例附近，做空Precision提高约0.19个百分点，但空头Recall和总体准确率下降。

14:30及以后：

| 指标 | 固定0.5 | 滚动分位数阈值 |
|---|---:|---:|
| 实际负类占比 | 46.04% | 46.04% |
| 预测做空占比 | 30.88% | 46.83% |
| 做空胜率/Precision | 50.86% | 50.37% |
| 空头召回率/Recall | 34.11% | 51.24% |
| 做多胜率/Precision | 55.70% | 57.36% |
| 总体方向准确率 | 54.21% | 54.09% |

解释：尾盘分位数阈值明显提高空头覆盖和Recall，但新增空单没有优势，空头Precision下降；保留下来的多单更强，做多Precision升至57.36%。

全体样本：

- 固定0.5：做空占比59.55%，做空Precision 51.10%，总体准确率51.20%。
- 分位数阈值：做空占比50.01%，做空Precision 51.20%，总体准确率50.99%。

### 4.3 方向发生变化的样本

14:30前：

- 固定空单→分位数多单：192,837笔，占13.19%。
- 该组Tag负类比例50.37%，Tag正类比例48.72%。
- 固定多单→分位数空单：仅126笔。

14:30及以后：

- 固定多单→分位数空单：34,487笔，占16.52%。
- 该组Tag负类比例49.60%，Tag正类比例49.98%，基本无方向优势。
- 这解释了尾盘新增空单为何没有提高做空Precision。

### 6.5 结果指标定义

- 预测做空占比：`预测为空的样本数 / 全部样本数`。
- 做空Precision：`预测为空且Tag<0的样本数 / 预测为空的样本数`。
- 空头Recall：`预测为空且Tag<0的样本数 / 全部Tag<0样本数`。
- 预测做多占比：`预测为多的样本数 / 全部样本数`。
- 做多Precision：`预测为多且Tag>0的样本数 / 预测为多的样本数`。
- 多头Recall：`预测为多且Tag>0的样本数 / 全部Tag>0样本数`。
- 总体方向准确率：`正确多单数+正确空单数 / 全部样本数`。
- 当前收益图的胜率排除`Tag=0`；做空占比仍以全部样本为分母。
- 单笔策略收益率：做多时为`Tag`，做空时为`-Tag`。
- 平均策略收益率：全部单笔策略收益率的算术平均。
- 每日开仓次数中位数：统计档位在范围内全部交易日的开仓次数中位数；无交易日期按0次计入。
- 平均每日收益：`平均策略收益率 × 每日开仓次数中位数`，表示典型频次下逐笔收益日内求和，不等同于日内资金均分后的账户收益。
- 胜率：在`Tag!=0`样本中，`单笔策略收益率>0`的样本占比。
- 平均盈利：只在`单笔策略收益率>0`的样本中计算平均值。
- 平均亏损：只在`单笔策略收益率<0`的样本中计算平均值，比较幅度时取绝对值。
- 平均盈亏比：`平均盈利 / abs(平均亏损)`。
- 期望R倍数：`胜率 × 平均盈亏比 - (1 - 胜率)`；`Tag=0`不参与计算，0为盈亏平衡。

### 6.6 分位数计算的防未来信息规则

- 每个评估交易日只使用该日之前的20个交易日。
- 14:30前历史数据只计算14:30前阈值。
- 14:30后历史数据只计算14:30后阈值。
- 当前日的score和Tag不参与当前日阈值计算。
- 最初20个交易日仅用于预热，不进入最终评价样本。
- 阈值每日更新，不是使用全样本一次性计算的常数。

## 7. 口径边界与容易产生歧义的事项

以下内容会直接影响统计结果的解释。交接时必须保留当前采用口径，同时明确哪些业务含义仍未最终确认。

### 7.1 “真实空单比例”的准确含义

- 当前脚本使用的是 `Tag<0` 的样本数占全部样本数的比例。
- 由于Tag是实际收益率，该指标的严谨名称应为“历史负收益样本占比”或“真实负类占比”。
- 它不是历史上实际执行过的空单数量占比，也不是策略真实持仓中的空头订单比例。
- 当前分位数阈值实际计算为：在历史score分布上，取“历史负收益样本占比”对应的分位数。

### 7.2 Tag的具体收益周期尚未最终确认

- 已确认：Tag的业务含义是收益率。
- 尚未确认：Tag究竟对应未来1、5、10、30或其他分钟周期，也未确认是否为简单收益率、对数收益率或其他标准化收益。
- 根据滞后相关结构，目前最合理的推断是未来约30个交易分钟收益，但这仍然只是数据推断。
- 最终确认需要标签生成代码，或使用原始分钟价格复算不同候选周期后与Tag逐项比对。

### 7.3 当前分位数阈值的聚合范围

- 当前14:30前后分别计算阈值。
- 每个时段内汇总全部合约、全部分钟样本计算历史负收益比例和score分位数。
- 当前不是按合约单独计算阈值，也不是按月份单独计算阈值。
- 因此当前阈值代表全合约总体口径，可能掩盖合约之间的分布差异。

### 7.4 样本权重

- 当前每一个“合约×分钟”样本权重相同。
- 没有按合约资金规模、成交量、持仓量、流动性或波动率进行加权。
- 同一分钟内多个合约会被视为多条独立样本。
- 如果实际交易资金在多个合约之间共享，样本统计不能直接等同于资金收益表现。

### 7.5 Tag等于0的处理

- 当前零阈值收益图将`Tag=0`排除在胜率分母之外。
- `Tag=0`仍计入样本量和做空占比，不影响方向样本总数。
- 历史报告中若存在把`Tag=0`计入分母的Precision或准确率，不能与当前胜率直接比较。

### 7.6 分数恰好等于阈值时的方向

- 当前规则为 `score < threshold` 做空。
- 当前规则为 `score >= threshold` 做多。
- 因此分数恰好等于阈值时归为多单。

### 7.7 收益累计方式

- 单笔收益统一为 `direction × Tag`，其中方向严格由`pred`与0比较得到。
- 每个Pred档位在交易日内对全部样本等权平均，再按`cumsum(当日等权收益)`进行跨交易日单利累计；无交易日期以0收益补齐。
- 对称配对组合先分别计算空腿和多腿日均收益，两腿各占50%，合并后同样按交易日单利累计。
- 尚未进行资金占用归一化，也未处理同一分钟多个合约同时产生信号的组合资金分配。

### 7.8 交易成本和执行约束

- 当前胜率、Precision、Recall和方向准确率均未计入手续费、滑点和冲击成本。
- 当前未处理合约换月成本、涨跌停、流动性不足和无法成交等执行问题。
- 当前也未限制同时持有的合约数量或总杠杆。
- 因此当前结果用于评价方向信号，不等同于可直接实现的净收益。

### 7.9 重叠标签与样本独立性

- Tag可能是未来约30个交易分钟收益，相邻分钟样本可能共享大量未来价格区间。
- 即使相邻Tag数值不完全相同，样本之间仍可能高度相关。
- 因此1,670,400个评估样本不能简单视为1,670,400个相互独立的统计观察。
- 当前文档报告的是描述性胜率和比例，未把重叠样本相关性纳入显著性检验。

## 8. 其他重要历史结论

### Tag周期推断

- 相邻分钟Tag完全相同并不普遍：14:30前约0.35%，14:30后约0.22%。
- 14:30前Tag滞后相关从lag1约0.957逐步衰减，到lag29约0.062、lag30约0.026。
- 当前最合理但未最终确认的推断：Tag可能是未来约30个交易分钟收益。
- 14:30后的标签可能跨收盘连接下一交易日，因此波动和相关结构明显不同。
- 最终确认仍需标签生成代码或原始分钟价格复算。

### 旧Plan B为什么不继续

旧方案使用滚动中位数相对0.5的偏置修正。结果显示修正可以改变多空比例，但新增空单没有稳定优势；尾盘修正越强，新增空单胜率从约50.92%下降到49.41%。因此已转向更可解释的分位数阈值方法。
