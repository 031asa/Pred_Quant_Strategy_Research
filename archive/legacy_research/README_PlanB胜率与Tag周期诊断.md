# Plan B胜率与Tag周期诊断

## 本阶段范围

- Plan B只比较多空方向、方向转换和胜率，不计算累计收益。
- `score = pred + 0.5`，分类中心为 `0.50`。
- 使用此前 `20` 个交易日的score中位数估计公共偏置。
- 14:30前后分别估计偏置，14:30整点属于后一段。
- 测试修正强度：0%, 25%, 50%, 75%, 100%。
- 最初 `20` 个交易日作为预热期，不进入方案比较。

## 胜率定义

- 做多胜率：`Tag > 0`。
- 做空胜率：`Tag < 0`。
- 最关键的转换组是“原做多、修正后做空”。如果该组做空胜率稳定提高，才说明公共多头偏置可能具有修正价值。

## 核心结果

- 全体样本中，修正强度从0%提高到100%后，做多占比由40.45%升至49.95%，做空占比由59.55%降至50.05%；做空胜率仅由51.10%变为51.16%，改善极小。
- 14:30以前，修正使多空占比趋近各半，但做多胜率由50.17%降至49.74%，做空胜率仅由51.11%变为51.29%，改善很弱。
- 14:30及以后，修正强度从0%提高到100%后，做空占比由30.88%升至50.47%，但做空胜率由50.86%降至50.29%。
- 最关键的“原做多、修正后做空”样本，其做空胜率随修正增强依次约为50.92%、50.68%、50.11%、49.41%，没有形成稳定优势。

因此，当前形式的Plan B虽然能改变多空方向比例，但没有实现“用一部分多头机会换取更高空头胜率”的目标。现阶段建议先暂停累计收益测算，避免把方向质量没有改善的结果误读为策略优化。

## Tag周期诊断

当前parquet只能用于推断，不能百分之百确认Tag公式。本次检查包括：

- 同一合约、同一交易日、同一时段内的Tag唯一值数量；
- 相邻分钟Tag完全相同和近似相同的比例；
- 连续相同Tag的最长持续分钟数；
- 1至60分钟的Tag滞后相关；
- Tag标准差和连续重复率的日内变化；
- 尾盘Tag均值最高、最低和中位附近三个典型日的分钟曲线。

若要最终确认Tag是未来1、5、10、30分钟收益，还是到收盘/下一交易日收益，仍需标签生成代码或原始分钟价格进行候选收益复算。

## Tag诊断结论

- 相邻分钟Tag完全相同并不普遍：14:30以前约0.35%，14:30及以后约0.22%。因此，“大量样本共享完全相同Tag”不是常态；此前看到的重复大值更像少数异常日期或特殊区段。
- 14:30以前的Tag滞后相关从1分钟的0.957逐步衰减，到29分钟约0.062、30分钟约0.026。这一形态非常接近约30分钟重叠未来收益标签。
- 14:30及以后即使相隔29分钟，相关性仍约0.575，同时Tag波动率在14:30附近明显跃升。
- 结合每日尾盘只有30条记录，当前最合理但尚未确认的推断是：Tag可能由“未来约30个交易分钟收益”生成；14:30后的标签可能跨过当日收盘，连接到下一交易日的分钟价格，因此出现更强的共同区间、相关性和波动。

这也解释了为什么14:30像一个特殊分界点：神秘的可能不是时钟本身，而是标签计算窗口从日内变成跨日。最终应通过标签生成代码确认，或用原始分钟价格分别复算未来1、5、10、20、30、60分钟收益，与现有Tag逐项比对。
