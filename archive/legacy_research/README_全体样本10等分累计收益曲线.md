# 全体样本10等分分时累计收益曲线

## 分组与方向

- 全体有效样本：1,728,000条
- score = pred + 0.5，并限制在[0,1]
- 按score排序后等样本10等分，每档172,800条
- Q01-Q05做空，策略收益=-Tag
- Q06-Q10做多，策略收益=Tag
- 做空档位使用绿色，期末累计收益率越大绿色越深
- 做多档位使用红色，期末累计收益率越大红色越深
- 颜色深浅由实际收益动态计算，不按Q档编号固定

## 分时图片

- `14:30以前`：使用全体样本的10等分边界，只保留Datetime < 14:30的1,512,000条信号
- `14:30及以后`：使用同一套全体边界，只保留Datetime >= 14:30的216,000条信号
- 14:30整点归入后一张图
- 两张图不重新计算分档边界，因此能够直接比较时段差异

## 时段内独立重新分档

- `14:30以前独立样本`：先筛选1,512,000条，再以该时段中位数0.483649重新10等分，每档151,200条
- `14:30及以后独立样本`：先筛选216,000条，再以该时段中位数0.538718重新10等分，每档21,600条
- 独立分档用于排除两个时段score分布位置不同造成的影响，直接观察各时段内部的排序能力

## 时序累计口径

1. 每个交易日、每个档位内的全部有效策略收益先等权平均。
2. 各档分别按交易日排序。
3. 累计收益率采用复利：`cumprod(1 + 每档每日等权策略收益) - 1`。
