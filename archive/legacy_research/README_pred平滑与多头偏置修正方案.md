# pred平滑与多头偏置修正方案

## 背景

现有结果显示，策略尤其在14:30以后更依赖多头收益：高分做多档位表现较好，而多数空头档位表现较弱。

考虑到金融数据噪声较大，现阶段不急于增加大量新特征或重新拟合复杂模型，而是先对现有pred进行简单修正，判断能否降低策略风险、减少多头依赖，并改善空头表现。

目前考虑以下两种方案。

## 方案A：设置不交易区间

在原有多空阈值附近增加一个不交易区域：

```text
分数明显高于中心：做多
分数明显低于中心：做空
分数接近中心：不交易
```

例如以0.5为中心，可以只在分数高于0.52时做多、低于0.48时做空，中间样本不参与交易。

这个方案的主要目的不是改变预测方向，而是过滤置信度较低的信号，使策略整体更加保守。

预期效果：

- 多头和空头交易数量都会减少；
- 可能损失部分收益；
- 如果被过滤的主要是错误信号，胜率和回撤表现可能改善；
- 如果收益与回撤只是同比下降，则本质上只是减少风险暴露，没有提高预测质量。

需要比较不同宽度的不交易区间，观察交易覆盖率、胜率、收益和最大回撤的变化。

## 方案B：去除pred中的多头公共偏置

如果近期pred整体偏高，策略可能会把部分接近阈值的样本判断为弱多头。方案B希望从所有预测值中减去一部分近期公共偏高量。

修正逻辑可以概括为：

```text
修正后分数 = 原始分数 - 部分近期多头偏置
```

修正后：

- 极端高分的强多头通常仍然做多；
- 阈值附近的弱多头可能转为空头；
- 原有空头信号可能得到增强；
- 策略允许损失一部分多头收益，换取空头胜率或空头收益改善。

近期偏置只能使用预测时点以前的数据估计，不能使用当月结束后才能得到的完整月度中位数。14:30前后应分别估计，因为两个时段的预测分布差异明显。

这个方案最重要的检查对象，是“原来做多、修正后转为空头”的样本：

- 如果这些样本的Tag通常小于0，说明修正确实找到了错误多头；
- 如果这些样本仍然普遍上涨，说明修正只是在误伤正确多头。

## 两种方案的区别

| 对比 | 方案A：不交易区间 | 方案B：去多头偏置 |
|---|---|---|
| 主要目标 | 过滤低置信度交易 | 调整多空结构 |
| 对预测方向的影响 | 保留方向，但部分样本不交易 | 边界样本可能由多转空 |
| 多头数量 | 减少 | 可能减少 |
| 空头数量 | 减少 | 可能增加 |
| 空头胜率 | 可能因筛选而提高 | 可能因纠正错误多头而提高 |
| 主要风险 | 过滤掉有价值的弱信号 | 将正确多头错误改为空头 |

方案A回答的是“这个信号是否足够强，值得交易”；方案B回答的是“模型是否存在可以修正的整体多头倾向”。

## 建议的研究顺序

两种方案先分别测试，不在第一轮同时使用：

1. 先测试不同宽度的不交易区间；
2. 再测试不同程度的多头偏置修正；
3. 分别观察全体样本、14:30以前和14:30以后；
4. 比较多头与空头的样本量、胜率、平均收益、累计收益和最大回撤；
5. 最终使用滚动样本外方式确认效果，避免利用未来数据。

如果方案A只能让收益和回撤同比缩小，说明它主要是降低风险；如果方案B增加了空头数量却没有提高空头胜率，说明现有pred可能缺少真正的空头信息，简单修正无法解决，需要再考虑新特征或重新建模。
