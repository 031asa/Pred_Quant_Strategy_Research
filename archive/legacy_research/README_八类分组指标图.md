# 八类分组指标图

## 输出内容

`八类分组指标图`文件夹内共8张高清PNG：

1. 全体样本20等分 - 14:30以前
2. 全体样本20等分 - 14:30及以后
3. 全体样本50等分 - 14:30以前
4. 全体样本50等分 - 14:30及以后
5. 14:30以前独立样本 - 20等分
6. 14:30以前独立样本 - 50等分
7. 14:30及以后独立样本 - 20等分
8. 14:30及以后独立样本 - 50等分

每张图直接标注平均策略收益、胜率和平均盈亏比。横轴下方显示档位、概率区间及当前口径的样本量。

## 计算口径

- score = pred + 0.5，并限制在[0,1]
- 阈值左侧做空，策略收益 = -Tag
- 阈值右侧做多，策略收益 = Tag
- 全体分组的4张图使用全体中位数0.487757
- 14:30以前独立分组使用该时段中位数0.483649
- 14:30及以后独立分组使用该时段中位数0.538718
- 14:30整点归入“14:30及以后”

## Jupyter运行

在PyCharm Jupyter中打开或粘贴`八类分组指标图_Jupyter源码.py`的单元格并依次运行。源码会复用同目录下的分析源码和参数文件，并自动生成8张图片。

需要的Python包：`polars`、`numpy`、`matplotlib`、`IPython`。
