# 阈值与区间分析使用说明

## 文件

- `阈值与区间分析_Jupyter源码.py`：核心分析源码，可在 Jupyter 或 PyCharm 中运行。
- `阈值分析参数.json`：统一参数文件，方向阈值和区间设置都从这里读取。
- `build-segmented-accuracy-report.mjs`：生成带格式 Excel 的构建源码。
- `按合约_按月份_阈值精确度分析.xlsx`：已经用完整 Parquet 数据计算好的结果。

## Excel 报告结构

- `分析报告`：整体 KPI、多空概览、全体区间表现、合约概览、近期 12 个月表现和自动结论；适合直接汇报。
- `累计收益曲线`：按固定方向阈值生成日频等权、复利累计收益曲线，并展示期末累计收益与最大回撤。
- `区间明细`：把全体、各合约、各月份的区间结果合并为一张可筛选长表。
- `阈值明细`：把全体、各合约、各月份的候选阈值结果合并为一张可筛选长表。

报告不再堆叠多张同类宽表；“盈利单数/亏损单数比”已改为胜率。区间样本占比低于 `report_min_interval_share` 时，主报告标记为“小样本”。

## Jupyter 运行

把 Python 源码和 JSON 参数文件放在同一目录，然后运行：

```python

```

## 参数

通常只需修改 `阈值分析参数.json`：

```json
{
  "source_path": "C:/Users/Hello/Downloads/pred_eval.parquet",
  "score_offset": 0.5,
  "score_min": 0.0,
  "score_max": 1.0,
  "direction_threshold": 0.5,
  "dense_half_width": 0.2,
  "dense_step": 0.02
}
```

- `direction_threshold`：固定多空方向阈值，本次为 0.5。
- `dense_half_width`：方向阈值左右密集分析的宽度，本次为 0.2。
- `dense_step`：密集区间步长，本次为 0.02。
- `report_min_interval_share`：主报告把区间标为“可参考”的最低样本占比，本次为 0.005（0.5%）。
- 默认边界为 `0、0.30、0.32……0.50……0.68、0.70、1.00`。

## 计算口径

### 移动阈值表

对于每一列候选阈值：

- `score > threshold`：做多。
- `score < threshold`：做空。
- `score == threshold`：不交易。
- 做多 Precision：做多且 `Tag > 0` 的数量 ÷ 做多数量。
- 做空 Precision：做空且 `Tag < 0` 的数量 ÷ 做空数量。
- 做多/做空 Coverage：对应方向数量 ÷ 组内全部样本数量。

### 固定方向阈值区间表

方向阈值固定为 0.5，仅查询不同预测分数区间：

- 左侧区间采用左闭右开 `[a,b)`，做空，策略收益率为 `-Tag`。
- 右侧区间采用左开右闭 `(a,b]`，做多，策略收益率为 `Tag`。
- 分数恰好等于 0.5 单列展示，但不交易。
- 区间平均策略收益率：该区间策略收益率的算术平均。
- 胜率：策略收益率大于 0 的数量 ÷（赚钱单数 + 亏钱单数）。
- 平均盈亏比：该方向赚钱单平均收益 ÷ 该方向亏钱单平均亏损绝对值。
  做多区间用正收益单均值除以负收益单均值绝对值；做空区间则按做空后的策略收益正负计算。
- 策略收益率等于 0 不计入盈亏数量；没有亏损单时结果留空。

### 累计收益曲线

- 使用 `direction_threshold` 作为给定阈值。
- 高于阈值做多取 `Tag`，低于阈值做空取 `-Tag`，等于阈值不交易。
- 同一天全部有效信号先等权平均，得到日均策略收益。
- 累计收益率采用复利口径：`cumprod(1 + 日均策略收益) - 1`。
