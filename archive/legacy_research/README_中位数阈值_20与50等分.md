# 三数据集独立中位数阈值：20等分与50等分

## 计算口径

- 全体样本数：1,728,000
- `score = pred + 0.5`，并限制在 `[0, 1]`
- 每张表均先筛选自己的数据，再以该数据集 score 的 50% 分位数作为方向阈值
- 阈值左侧做空，策略收益取 `-Tag`
- 阈值右侧做多，策略收益取 `Tag`
- 等于阈值的样本不交易；本次数据该类样本为 0
- 左侧区间采用 `[a,b)`，右侧区间采用 `(a,b]`

## 14:30时间分段

- `Datetime < 14:30`：归入“14:30以前”
- `Datetime >= 14:30`：归入“14:30及以后”，因此14:30整点属于后一段
- 14:30以前：1,512,000条
- 14:30及以后：216,000条
- `全体样本`表的每个区间横向对比两个时间段的样本量、平均策略收益、胜率、平均盈亏比

## 结果结构

- `全体样本`：1,728,000条，中位数 `0.48775737546057296`；20等分每档86,400条，50等分每档34,560条
- `14:30以前`：1,512,000条，中位数 `0.48364895708907124`；20等分每档75,600条，50等分每档30,240条
- `14:30及以后`：216,000条，中位数 `0.5387180558768176`；20等分每档10,800条，50等分每档4,320条
- 每张工作表均同时包含20等分和50等分；左半区间做空，右半区间做多
- 所有等分档位样本数完全相等，最大档位样本差为0
- 后两张表使用各自数据集的中位数，不沿用全体中位数
