本项目以`data/pred_eval.parquet`为原始输入，汇总此前的阈值、分组收益、14:30分时、Tag周期和Score漂移研究，并交付当前采用的“14:30前后独立漂移修正 + 零中心Pred”流程。

## 当前数据和方向口径

- 原始样本1,728,000条，600个交易日，12个合约，时间为2024-01-03至2026-06-30。
- `score = clip(pred + 0.5, 0, 1)`；`Tag`为实际收益率。
- `Datetime < 14:30`属于盘中，14:30整点及以后属于尾盘。
- 两个时段独立计算扩展中位数慢速基准、因果EWMA近期中心和开发段固定平衡偏移。
- 完整首个自然月21个交易日为冷启动；最后60个交易日封存测试；Tag不参与选参。
- 最终信号定义为`pred_final = adjusted_score - slow_baseline`，所以`pred < 0`做空、`pred >= 0`做多。
- 最终Parquet保留1,667,520条有效样本，字段仍为`Date, Contract, Datetime, pred, Tag`。

## 当前结论

两段均选中1日半衰期。最终60日测试段：

| 时段 | 指标 | 修正前 | 修正后 |
|---|---|---:|---:|
| 14:30前 | 月度绝对面积 | 0.005879 | 0.001707 |
| 14:30前 | 总体方向准确率 | 50.57% | 49.99% |
| 14:30前 | 平均策略收益率 | 0.00006129 | 0.00000129 |
| 14:30后 | 月度绝对面积 | 0.022829 | 0.008160 |
| 14:30后 | 总体方向准确率 | 46.00% | 47.60% |
| 14:30后 | 平均策略收益率 | -0.00129224 | -0.00122131 |

结论是：14:30前“曲线变平但方向效果下降”；14:30后“部分方向指标改善、亏损略收窄，但尚未形成有效盈利策略”。

最终Pred的总体10等分中，Q10做多的样本胜率约52.88%、逐样本盈亏比约1.266、盈利日胜率约59.68%、日收益盈亏比约1.351，日内等权后按交易日复利的期末累计收益约56.06%。该结果未计手续费、滑点和资金占用。

## 历史工作摘要

此前已完成固定0.5阈值、ROC/AUC、10/20/50等分、14:30分界、累计收益、Pred与Tag漂移、Tag重叠周期、Plan B滚动中位数偏置修正、分时滚动分位数阈值以及旧总体Score漂移实验。历史数值和判断保留在`result/历史说明/`与`result/报告/`的README、PDF、Word和交接文档中；旧Excel、CSV、诊断JSON、旧图和旧源码已从精简交付中移除。

主要历史判断：

1. 14:30前后是两种不同预测状态。
2. 固定0.5使盘中过度判空；校准多空比例不等于提高预测效果。
3. Score漂移可以压平，但仅优化分布稳定性可能损害样本外收益。
4. 信号优势集中在分布两端，尤其高分做多端；中间档位较弱。
5. Tag可能是约30分钟重叠未来收益，分钟样本不宜视为完全独立。

## 复现顺序

```powershell
python 'scripts\总体Score时序漂移.py'
python 'scripts\导出分时漂移修正后Pred.py'
python 'scripts\修正后Pred分组收益.py'
python -m unittest discover -s tests -v
```

三步依次输出参数与两张漂移图、最终零中心Parquet、七张分组与收益图。具体文件索引见`result/README.md`。

## 边界

- 每个“合约×分钟”样本等权，未按资金、成交量或波动率加权。
- 方向命中率排除`Tag=0`；阈值等号归为做多。
- 未计手续费、滑点、冲击成本、换月成本和多合约资金占用。
- 相邻分钟可能共享未来收益区间；Tag的准确生成周期仍需标签源码确认。
