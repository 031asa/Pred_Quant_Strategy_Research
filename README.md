# Pred量化策略研究：最终工作汇总

本项目以`data/pred_eval.parquet`为原始输入，汇总此前的阈值、分组收益、14:30分时、Tag周期和Score漂移研究，并交付当前采用的“14:30前后独立漂移修正 + 零中心Pred”流程。

## 当前数据和方向口径

- 原始样本1,728,000条，600个交易日，12个合约，时间为2024-01-03至2026-06-30。
- `score = clip(pred + 0.5, 0, 1)`；`Tag`为实际收益率。
- `Datetime < 14:30`属于盘中，14:30整点及以后属于尾盘。
- 两个时段独立计算扩展中位数慢速基准、因果EWMA近期中心和开发段固定平衡偏移。
- 完整首个自然月21个交易日为冷启动；最后60个交易日封存测试；Tag不参与选参。
- 最终信号定义为`pred_final = adjusted_score - slow_baseline`，所以`pred < 0`做空、`pred >= 0`做多。
- 最终Parquet保留1,667,520条有效样本，字段仍为`Date, Contract, Datetime, pred, Tag`。

## 当前结论

两段均选中1日半衰期。最终60日测试段：

| 时段 | 指标 | 修正前 | 修正后 |
|---|---|---:|---:|
| 14:30前 | 月度绝对面积 | 0.005879 | 0.001707 |
| 14:30前 | 总体方向准确率 | 50.57% | 49.99% |
| 14:30前 | 平均策略收益率 | 0.00006129 | 0.00000129 |
| 14:30后 | 月度绝对面积 | 0.022829 | 0.008160 |
| 14:30后 | 总体方向准确率 | 46.00% | 47.60% |
| 14:30后 | 平均策略收益率 | -0.00129224 | -0.00122131 |

结论是：14:30前“曲线变平但方向效果下降”；14:30后“部分方向指标改善、亏损略收窄，但尚未形成有效盈利策略”。

在相同的1,667,520条有效样本上，调整前总体`pred < 0`占59.60%，调整后为49.94%。零阈值指标逐样本以`pred < 0`做空、`pred >= 0`做多；累计曲线先在档内计算当日等权收益，再按交易日单利累计。配对组合固定低档做空、高档做多，两腿日均收益各占50%。总体零阈值胜率为51.61% → 51.36%。该结果未计手续费、滑点和资金占用。

## 历史工作摘要

此前已完成固定0.5阈值、ROC/AUC、10/20/50等分、14:30分界、累计收益、Pred与Tag漂移、Tag重叠周期、Plan B滚动中位数偏置修正、分时滚动分位数阈值以及旧总体Score漂移实验。历史数值和判断保留在`result/historical_notes/`与`result/reports/`的README、PDF、Word和交接文档中；旧Excel、CSV、诊断JSON、旧图和旧源码已从精简交付中移除。

主要历史判断：

1. 14:30前后是两种不同预测状态。
2. 固定0.5使盘中过度判空；校准多空比例不等于提高预测效果。
3. Score漂移可以压平，但仅优化分布稳定性可能损害样本外收益。
4. 信号优势集中在分布两端，尤其高分做多端；中间档位较弱。
5. Tag可能是约30分钟重叠未来收益，分钟样本不宜视为完全独立。

## Streamlit双组流水线实验

安装依赖并从项目根目录启动：

```powershell
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

项目内`.streamlit/config.toml`将服务绑定到`127.0.0.1`，页面只允许运行机器本机访问，单个上传文件上限为1GB。Windows、Linux和WSL均使用同一启动命令；WSL通常可直接从Windows浏览器访问终端给出的`localhost`地址。若部署在远程Linux主机，需要按所在网络的安全策略显式覆盖监听地址和防火墙配置。上传Parquet后会自动识别并要求确认`Datetime`、`Contract`、`pred`和`Tag`四个字段；无法唯一识别时使用下拉框手动映射。上传数据和临时图片不写入`data/`或`result/`。

A、B两组从相同原始数据独立开始，每组可自由新增、删除、启用、上移和下移模块：

- `按合约预处理`：给之后的平滑增加合约维度；每条流水线最多一次。
- `按时段预处理`：默认切点为14:30且可修改，并在该步骤选择“前后都保留并分别处理”“仅保留切点前”或“仅保留切点及以后”；筛选立即影响后续平滑，每条流水线最多一次，切点时刻归入后半段。
- `因果动态基准平滑`：按执行到该步骤时已经存在的分组独立平滑，可重复添加；每次都会重新建立动态基准并独立消耗冷启动期。

合约和时段维度会叠加。例如`按合约 → 平滑 → 按时段（前后都保留） → 平滑`先进行合约级平滑，再进行“合约×时段”平滑；它与`按合约 → 按时段 → 平滑`不是同一实验。选择“仅切点前/后”时，另一部分数据会在预处理步骤直接删除，动态基准只使用保留范围。空流水线直接使用原始Pred，可作为对照组。

每组的出图设置只选择六指标、零阈值单利累计、对称配对单利累计或Pred分布图；图表自动使用该组流水线最终保留下来的全部数据，并在标题和结果卡片中注明范围。结果摘要以一张全宽A/B对照表显示；结果图默认上下完整排列，也可切换为适合宽屏的左右并排，切换布局不会重新执行流水线。Web图由Plotly在浏览器内交互渲染，可缩放、悬停查看数值，并通过右上角相机按钮直接下载2倍分辨率PNG；页面另提供一份完整实验JSON下载。JSON包含文件哈希、字段映射、执行顺序、预处理范围、自动选参结果及最终有效日期和样本量，不导出处理后的Parquet。

项目在`static/fonts/`内置并随包分发`Noto Sans CJK SC`及其OFL许可证。Streamlit通过原生`theme.fontFaces`加载该字体，框架图标仍使用独立的Material Symbols字体；Plotly浏览器图和原有Matplotlib批量图也显式使用项目字体。因此不依赖Windows的微软雅黑，不要求Linux/WSL预装中文字体，也不会把展开箭头等内置图标显示成文字。浏览器端PNG下载不依赖服务器上的Chrome或Kaleido。

完整数据有172.8万行。建议运行时至少预留8GB可用内存，并在修改完流水线后再点击一次“执行A/B实验”；仅调整出图类型不会重新运行平滑。

## 边界

- 每个“合约×分钟”样本等权，未按资金、成交量或波动率加权。
- 六联图中的每日开仓次数中位数基于范围内全部交易日计算，无交易日按0次计入；平均每日收益为均笔收益乘每日开仓次数中位数，表示典型频次下的逐笔收益日内求和指标，不等同于累计曲线的日内资金均分收益。
- 方向命中率排除`Tag=0`；阈值等号归为做多。
- 未计手续费、滑点、冲击成本、换月成本和多合约资金占用。
- 相邻分钟可能共享未来收益区间；Tag的准确生成周期仍需标签源码确认。
